# 読書アウトプットノート

読んだ本をアウトプットして、知識の定着と行動につなげるためのWebアプリです。
スマホとPCのどちらからでも使えます（ホーム画面に追加するとアプリのように使えます）。

## できること

- **基本情報**：表紙、タイトル、著者、出版社、読了日、評価（★5段階）、タグ
- **ひとこと紹介**：「この本は〇〇な本」を一言で（80字まで）
- **簡単な紹介**
- **章ごとのまとめ**：序章、第1章、第2章…（追加できます）
- **心に残った一文**：最初に3枠（追加できます）
- **すぐに行動に移すこと**：チェックリスト。最初に3枠（追加できます）
- **本棚**：検索、タグでの絞り込み、並び替え
- **LINEで送る**：送る項目を選び、文面を確認・修正してから送れます
- **自動入力**：バーコード読み取り、またはタイトル・ISBNでの検索
- **バックアップ**：書き出しと読み込み（右上の「…」から）

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 画面の枠組み |
| `style.css` | 見た目（ノート風デザイン） |
| `app.js` | 動き（保存、検索、LINE送信など） |
| `manifest.webmanifest`, `icon*.png`, `icon.svg` | ホーム画面に追加したときのアプリ名とアイコン |

## 使っている無料サービス（登録は要りません）

- 国立国会図書館サーチ API：本の検索（タイトル、著者、出版社、ISBN）
- openBD／版元ドットコム：表紙画像
- Google Books API：予備の検索先
- html5-qrcode：バーコード読み取り（カメラ）
- LINE の共有URL（`https://line.me/R/share`）：LINE送信

## GitHub Pages での公開手順

1. GitHub で新しいリポジトリを作ります（例：`book-note`）。
2. このフォルダのファイルをすべてアップロードします。
3. リポジトリの **Settings → Pages** を開き、Branch を `main`、フォルダを `/ (root)` にして保存します。
4. 1〜2分で `https://<ユーザー名>.github.io/book-note/` から使えるようになります。
5. スマホで開いて「ホーム画面に追加」すると、アプリのように使えます。

※ バーコード読み取りのカメラは、https のページ（GitHub Pages は https です）でのみ動きます。

## データの保存について（段階1）

いまは記録を**端末のブラウザの中**に保存しています。

- スマホとPCのデータは別々です。移すときは「バックアップを書き出す」で保存したファイルを、もう一方の端末で「読み込む」してください。
- ブラウザのデータを消すと記録も消えます。ときどき書き出しておくと安心です。

## 次の段階：クラウド保存（Firebase + Googleログイン）

`app.js` の `Store`（データ保存の部分）だけを Firebase 版に差し替えれば、スマホとPCで自動的に同じデータになります。画面側を作り直す必要はありません。
